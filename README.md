# Установщик Heroes 3 HotA + HD

Скрипт [Inno Setup 7](https://jrsoftware.org/isinfo.php), который собирает установщик из готовой папки Heroes of Might and Magic III: Horn of the Abyss + HD mod — со своими картами, кампаниями и настройками. Внешне и по галочкам повторяет официальный установщик HotA, а главное — **пересобирается из любой установленной копии**: поставил на другой машине, добавил карт, собрал новый setup.

Скриншоты и подробности — в [посте в блоге](https://x-crm.in/2026/09/26/hota-installer-iss.html).

## Возможности

- Упаковывает всю папку игры, кроме сохранений (`games`), деинсталлятора (`Uninstall_HotA`) и готовых сборок (`_ISS\Output`)
- Устанавливает проект (`_ISS`) вместе с игрой, поэтому установщик можно собрать заново прямо из установленной копии
- Сам подставляет версии в приветствие («HotA 1.8.1 + HD 5.8 R20»): HotA — из `HotA_Setup.ini`, HD — из `_HD3_Data\HD3_Update.exe`
- Выглядит как оригинал: классический мастер, картинки и иконка официального установщика, те же тексты; русский и английский интерфейс
- Галочки как в оригинале: ассоциации `.h3t` / `.h3m` / `.h3c` с редакторами HotA, автообновление (`AutoUpdate` в `HotA_Setup.ini`), ярлык на рабочем столе (ведёт на HD Launcher)
- Ставит без прав администратора, для текущего пользователя; не даёт выбрать Program Files и всегда спрашивает папку
- Ярлыки в меню «Пуск»: игра, HD Launcher, редактор карт; после установки предлагает запустить HD Launcher

## Сборка

1. Положи файлы репозитория в подпапку `_ISS` папки игры:
   ```
   Heroes3_HotA\
   ├── _ISS\
   │   ├── heroes3_hota_3.iss
   │   ├── WizardImage.bmp
   │   ├── WizardSmallImage.bmp
   │   └── HotA.ico
   ├── Data\
   ├── Maps\
   └── ...
   ```
2. Установи [Inno Setup 7](https://jrsoftware.org/isdl.php). Его установщик можно положить в `_ISS` — тогда он поедет вместе с игрой на другие машины.
3. Открой `heroes3_hota_3.iss` в Inno Setup и нажми **Ctrl+F9** или собери из командной строки в папке игры:
   ```
   "C:\Program Files\Inno Setup 7\ISCC.exe" _ISS\heroes3_hota_3.iss
   ```
4. Готовый установщик появится в `_ISS\Output\Heroes3_HotA_<версия>_Setup.exe`.

## Правки на другой машине

Ставишь игру из собранного установщика → в установленной папке уже есть `_ISS` → добавляешь карты в `Maps`, меняешь настройки → собираешь заново (шаги 3–4). Путь к игре скрипт вычисляет относительно своего расположения, править его не нужно.

Нюансы:

- Установка поверх существующей копии только добавляет и заменяет файлы: то, что удалено в новой сборке, в старой копии останется.
- Деинсталлятор удаляет игру вместе с `_ISS` — не удаляй копию, из которой собираешь.

## Что можно поменять

| Параметр | Что задаёт |
|---|---|
| `MainExe` | Куда ведёт ярлык «Heroes 3 HotA» в меню «Пуск»: `HotA_launcher.exe`, `HD_Launcher.exe` или `h3hota HD.exe` |
| `UninstDir` | Папка деинсталлятора, как у оригинала — `Uninstall_HotA` |
| `AppId` | Свой (`Heroes3_HotA_HD`), чтобы не смешиваться с официальным установщиком HotA |

## Файлы

- `heroes3_hota_3.iss` — скрипт
- `WizardImage.bmp` (164×314), `WizardSmallImage.bmp` (55×58) — картинки мастера, вырезаны со скриншотов официального установщика
- `HotA.ico` — иконка из деинсталлятора официального установщика

Игры в репозитории нет. Картинки и иконка принадлежат HotA Crew, скрипт — под лицензией MIT (см. [LICENSE](LICENSE)).
